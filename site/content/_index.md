title = "Rusty Todo.txt Manager"
description = "Your todo.txt, on every desktop and in the terminal."
+++

rtm keeps your tasks in a plain [Todo.txt](https://github.com/todotxt/todo.txt) file that any
other Todo.txt tool can read. Use the desktop app, the command line, or both on the same file.

- **Plain text.** Your list stays an ordinary `todo.txt`; rtm reads and writes the standard format.
- **Desktop app and CLI.** `rtmapp` for point and click, `rtmcli` for the terminal and scripts.
- **Priorities, projects and contexts.** `(A)`, `+project` and `@context`, as Todo.txt defines them.
- **Dates.** Due and threshold (`t:`) dates, and recurring tasks that come back when you complete
  them; the CLI lists what is due today, this week or overdue.
- **Sync through Git or Pijul.** Keep the file in a repository and rtm pulls, commits and pushes
  for you, with your own SSH keys and credential helpers.
- **GNU/Linux, macOS and Windows.** Built and packaged for each.
