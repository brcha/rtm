rtm 26.3.0 archives done items, lets you edit an item's whole todo.txt line in the desktop app,
and keeps your files safe when a save goes wrong. It also includes every fix of 26.2.1.

- **Archive.** Done items move to the file's archive, `done.txt` next to `todo.txt` (or
  `work.done.txt` next to `work.txt`): from the desktop app's menu or automatically once they
  are a set number of days old, with `rtmcli archive`, or from an AI assistant through the MCP
  server. In a synced folder, the todo file and its archive are committed together.
- **Whole-line editing.** The desktop app's edit dialog holds the item's whole line, kept in step
  with the priority, date, recurrence, project and context fields, so a `+project` or `@context`
  can be typed anywhere in it. The list shows each line as written, with projects and contexts in
  place. Done items open read-only.
- **Desktop app.** Links in an item's text open in the browser, the start page offers New File
  and Load File while no file is open, and the sidebar lists only the projects and contexts that
  have active items. A click on one of two identical lines acts on that line, a failed save keeps
  your changes, and a config file that cannot be read is never overwritten.
- **Safer files.** The todo file and the app's config are replaced in one step, so a crash or a
  full disk never leaves them empty. `rtmcli add` refuses a todo file it cannot read and text
  with a line break. A symlinked todo file is refused, naming the file to open instead. Checking
  a Pijul repository no longer adds an untracked todo file to it.
- **Development.** CI caches the Rust and Nix builds, and the release tags are protected.
